# Wetness
对于雨水天气，我们先来处理湿润的情况，用饱和度来控制即可
首先是基础的颜色，我们利用`Diffuse`贴图以及`Desaturation`节点（虚幻内置的去饱和度节点），所以我们的`Fraction`要设置为负数

![输入图片说明](/imgs/2026-08-16/ERHzzqWbSpcA9afP.png)

对于`Specular`和`Roughness`的处理
`G`通道是`Roughness`，然后我们`Specular`默认放`0.5`，将其`append`，然后和湿润状态参数做`lerp`，最后用`mask`拆出来各自送到`Specular`和`Roughness`

#### 为什么选这一组数值 (0.07,0.3)

1.  **0.07 是水的 F0（菲涅尔 0° 反射率）**
    
    PBR 里 Specular 本质就是非金属 F0。水真实物理 F0≈0.07，沾水后表层覆盖一层水膜，所以 specular 强制改成水的物理高光，而不用原来材质的高光值。

> UE 默认 specular=0.5，是塑料 / 油漆，水的反射远弱于塑料，所以降到 0.07。

2.  **Roughness=0.3**
    
    真实水面如果是薄薄一层水膜，不会是完美镜面 roughness=0。物体表面本身有微小凹凸，薄水膜会继承底层表面微小扰动，所以给 0.3，得到湿润但不是镜子的质感。

-   如果改成 0，就变成像贴了一层完美镜面水，不真实；
-   如果大于 0.4，湿润效果不明显，看起来只是稍微变暗。

看左边已经有湿润的感觉了

我们后续会有许多材质需要复用这个湿润效果，所以可以封装成一个`MaterialFuction`，开放几个`input`和`output`

# 动态雨滴
`RG`通道是法线贴图，因为雨滴落到地上一般是平面的，所以不需要`Z`信息，所以就用两个通道寸

![输入图片说明](/imgs/2026-08-16/VMkSQFhqVacIkRfJ.png)

`B`通道是时间函数
`A`通道是用来区分大小雨滴的，效果上大雨滴会消散小雨滴不会
黑色的是小雨滴，白的是大的，中间灰色用来区分隔离

![输入图片说明](/imgs/2026-08-16/ydnyUld31z98XHr5.png)

先处理法线，因为这里不太一样，一般我们法线直接采样连到`normal`即可，但是那样子前提是因为我们的贴图已经被标识为法线。
但是这里只有`RG`通道是法线，后面是其他的，自然不能这么干，所以我们要自己将贴图的`0~1`映射到`-1~1`，然后我们可以自己乘上一个法线强度
![输入图片说明](/imgs/2026-08-16/Xy5RGGMkqplHOMLY.png)

下面这个，我们利用之前提到的`B`是时间信息，我们让它减去`time`，因为`time`是不断变化的，所以我们让两个值相减然后取小数部分，这样就可以让所有的水滴法线从存在到消失反复运行

![输入图片说明](/imgs/2026-08-16/gz8ur1Tjfr86yFqI.png)

优化一下现在希望小的保留，大的从存在到消失反复运行。
只需要拆出来即可
原本`A`通道存的信息就是用来判断用的，小雨滴是黑色`0`，大雨滴是白色`1`，中间是灰色`0.4`左右。这样子我们乘`2`减`1`的话就可以把小雨滴映射到`-1`，大雨滴映射到`1`。
小雨滴加`0.5`再乘`-1`主要是要防止灰色进入污染，因为图中的灰色大概是`0.4`，`0.4 * 2 - 1`，所以再加上`0.5`然后乘`-1`就会负数，最终只有小水滴是`1`。
然后大小雨滴`add`并作为`mask`乘上法线即可

![输入图片说明](/imgs/2026-08-16/DyUxuENwYk2cDcwA.png)

我们利用`vertexNormalWS`，取`B`通道，也就是`Z`向量，然后用`saturate`这样就能只保留向上的法线了，然后用这个作为`mask`，和大小雨滴的`add`结果相乘，这样子就可以只保留最顶面有雨水效果了

![输入图片说明](/imgs/2026-08-16/bp482I6ddWTodS7x.png)

把大小雨滴的蒙版结果`0~1`做`0.1`次方放大（`1`的次方还是在`1`之内），然后用`1-x`，这样就能做到水滴显现之处光滑（因为原本水滴最明显的时候就是`1`，但是`roughness`越小越光滑，所以是`1-x`），可以反射场景

![输入图片说明](/imgs/2026-08-16/awgTVoQDyMxmxFQ6.png)

依旧是换到`MaterialFunction`，然后在这里加一个`Rain`强度，其实也很好理解，默认`1`的话就是顶部全显现，越小就是越不明显（雨越小的感觉）

![输入图片说明](/imgs/2026-08-16/3EQ48vJu2KnDYh8B.png)

# 水滴滑落效果
用到两张贴图
一张和上一个一样
`RG`是法线，`B`是水滴滑落的蒙版，`A`是时间变化的数据
还需要一张贴图是从上到下的变化数据，用来做水滴滑落的效果

![输入图片说明](/imgs/2026-08-16/aZE60B9mVrzr4L1g.png)

我们要处理的是侧面，首先我们先用绝对世界坐标去采样，但是坐标对于采样太大了，需要进行缩放
绝对世界位置 = 物体上每一个点，在整个关卡大世界里的真实坐标，不受物体缩放、旋转、位移影响。
1.  **绝对世界位置（你现在用的）**
    拿的是**关卡全局空间坐标**。物体挪位置，贴图条纹就跟着物体一起挪。
> 你现在材质效果：方块一移动，上面的彩色条纹会跟着方块跑。
2.  **物体局部位置（Object Local Position）**
    只看物体自己本身，方块中心点永远是 (0,0,0)，物体怎么在场景里挪，这个值不变。贴图固定贴在模型身上，物体移动条纹不会漂移。

所以我们得用世界，不能用局部，要不然旋转立方体的时候，贴图会死死跟着立方体旋转，不是我们想要的雨水永远竖直下落的效果

比如现在我们要采样`XZ`这个面，那就是`mask`取`RB`，同理`YZ`面就是`GB`

![输入图片说明](/imgs/2026-08-18/MhTVLgN3A2Qzn8sZ.png)

让四周正确采样很简单，只要通过`lerp`就行了，当`alpha = 0`的时候用上面，`1`的时候用下面，`round`是四舍五入
所以用`R`通道`mask`，比如前面的面，那肯定`Y`是`1`，`X`是`0`，所以会走上面，合理

![输入图片说明](/imgs/2026-08-18/dQhfCsMWceMW7UUa.png)

然后就正常采样`RG`得到法线，映射到`-1~1`，然后`append`形成三维向量并单位化，最后连法线上

![输入图片说明](/imgs/2026-08-18/MKqNVkySXm8dAor5.png)

这时候开始引入水滴下落的`mask`，是一个竖条。
还是用世界坐标采样，不过这时候我们要加上`time`，我们对于`uv`其实只想改变`v`，`u`正常采样即可，所以把`RB`用`mask`拆出来（`G`是朝向屏幕的`Y`我们不用）。这样就可以实现一个横条向下滑动的效果

# 涟漪
对着图片捋一捋
首先用`frac`获取小数，是因为防止颜色值过大造成高亮
其次为什么要用`subtract 1`，是因为看下面的贴图，中心值大约为`0.6`左右，如果我们不`-1`，那意思就是在贴图基础上叠加了，不会从中心点扩散白色出去，而是在贴图的基础上叠加白色扩散。
最后捋一下这些乘数
比如：
`Multiply ×20`：放大相位差
原始相加结果范围大概 \([-1,1]\)，**乘以 20，放大到 [-20,20]**。
> 乘大系数 = 增加波纹圈数。系数越大，同样径向距离内波纹越密。 这里乘 20，本来会产生非常非常多圈涟漪。

`Clamp (Min=0, Max=5)` 截断到 `0‑5`
**这是最关键的一步！**

-   把小于 0 全部掐成 0，大于 5 全部掐成 5。
-   小于 0 区域：输出固定 0 → (`sin(0)=0`) → UE Sine 输出 = 0.5（中性灰色，**看不见波纹**）。
> 效果：**波纹不会出现在中心区域，中心直接 “关闭波纹”**。只有相位大于 0 的地方才开始出现涟漪。
-   上限掐到 5：不让相位无限制变大，把最大相位锁死在 5。防止边缘波纹密度爆炸。

> 物理效果：波纹是一圈圈向外扩张，**中心区域永远是平静无波纹，波纹环从某个半径才开始出现，向外传播**。 如果不做 clamp，从模型正中心就会密密麻麻全是波纹。

结果 `× Pi`（乘以 `π≈3.14159`）
Clamp 输出范围：`0 ~ 5`，乘以 π 后相位范围变成：`0~5Π`弧度。


![输入图片说明](/imgs/2026-08-25/Cqdc1NYuEy259LPy.png)

#### 举几个直观例子

1.  **Clamp 输出 = 1，乘 π →相位 = 1π** (`sin(pi)=0`) → Sine 输出 = 0.5（中间灰色）
2.  **Clamp 输出 = 0.5，乘 π →相位 = 0.5π** \(`sin(pi/2)=1`) →输出 = 1（最亮，波纹白边）
3.  **Clamp 输出 =1.5，乘 π →相位 = 1.5π** \(`sin(3pi/2)=-1`) →输出 = 0（最暗，波纹黑谷）

> 每增加 1（Clamp 的输出值），相位增加 π，完成**半圈波纹（亮变暗）**。
> 
> -   Clamp 区间 0~5：0 →5，一共增加 5 个 π，正好 2.5 个完整正弦振荡，也就是画面上看到**2 条亮波纹**。

`G`通道是法线，由于极坐标编码贴图，需要极坐标转笛卡尔
已知角度`θ`，单位向量（长度 = 1）：
`X = cos(θ), Y = sin(θ)`
